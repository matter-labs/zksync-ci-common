# TypeScript and JavaScript

Check changed data flows across request parsing, validation, authorization, persistence, serialization, browser sinks,
and outbound requests. Look for unsafe type assertions that remove runtime validation, prototype pollution, command or
query injection, SSRF, XSS, token leakage, insecure deserialization, and async races with security consequences.

Do not flag TypeScript type weakness by itself. Establish the runtime path and security impact.
