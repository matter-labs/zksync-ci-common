# Compilers, virtual machines, and execution engines

Check source, IR, bytecode, and runtime semantic agreement; instruction decoding and validation; gas and resource
metering; memory, address, and integer bounds; host and guest isolation; undefined behavior; nondeterminism; and version
or feature-gate mismatches across compilation and execution.

A finding must demonstrate a miscompile, invalid program acceptance, sandbox escape, accounting bypass, or consensus
divergence. Do not report compatibility differences that cannot affect a supported program or security boundary.
