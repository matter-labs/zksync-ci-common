# HTTP, RPC, and network services

Check parsing and validation boundaries, authentication state, object binding and mass assignment, ambiguous content
types, file handling, redirects and callbacks, outbound destinations, proxy behavior, error and timing disclosure,
pagination and query complexity, rate limits on expensive operations, request amplification, and inconsistent validation
across equivalent HTTP, RPC, WebSocket, or internal entry points.

Report denial of service only when the trigger is cheap or repeatable for the attacker and the resource impact is
material.
